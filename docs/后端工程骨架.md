# 后端工程骨架

> 目录：`exam-backend/`　构建：Maven　JDK 17+　Spring Boot 3.5

## 一、技术栈

| 分类 | 技术 |
|------|------|
| 基础框架 | Spring Boot 3.5 |
| 持久层 | MyBatis-Plus（通用 Mapper + 分页） |
| 权限认证 | Sa-Token（RBAC 三级角色鉴权） |
| 数据库 | MySQL 8.0 |
| 接口文档 | Knife4j（OpenAPI 3，在线调试） |
| 工具库 | Hutool、EasyExcel（导入导出）、Jackson（JSON） |

## 二、分层架构

采用经典的 **Controller → Service → Mapper** 三层结构，配合统一的 DTO/VO 做入参出参隔离：

```
HTTP 请求
   │
   ▼
Controller 控制层  ── 参数校验(@Valid)、角色鉴权(StpUtil.checkRole)
   │
   ▼
Service 业务层  ── 业务逻辑、事务、判分引擎、统计聚合
   │
   ▼
Mapper 持久层  ── MyBatis-Plus BaseMapper + 自定义 SQL
   │
   ▼
MySQL 数据库
```

关键约定：

- **入参用 DTO**（`dto` 包），**出参用 VO**（`vo` 包），**数据库对象用 Entity**（`entity` 包），三者不混用。
- **统一响应体**：所有接口返回 `Result<T>`，分页返回 `PageResult<T>`。
- **统一异常**：业务异常抛 `BusinessException`，由 `GlobalExceptionHandler` 兜底转成 `Result`。

## 四、核心组件说明

### 1. 统一响应体 `Result<T>`

```json
{ "code": 200, "message": "success", "data": { ... } }
```

- `success(data)` / `success()`：成功（code=200）
- `error(message)` / `error(code, message)`：失败

### 2. 分页响应体 `PageResult<T>`

```json
{ "total": 123, "records": [ ... ] }
```

### 3. 全局异常处理 `GlobalExceptionHandler`

统一捕获并转换：

- `BusinessException`：业务异常，直接返回其 message
- 参数校验异常（`@Valid` 触发）：返回第一条校验错误
- `NotLoginException`（Sa-Token）：未登录，返回 401
- 其它异常：兜底返回系统错误，避免堆栈泄露到前端

### 4. Sa-Token RBAC 鉴权

- `SaTokenConfig`：配置拦截规则，放行登录接口与静态资源。
- `StpInterfaceImpl`：实现 `getRoleList` / `getPermissionList`，从 `sys_user_role` 查询当前用户角色。
- 控制器内用 `StpUtil.checkRoleOr("ADMIN", "TEACHER")` / `checkRole("ADMIN")` 做**接口级**鉴权。

角色与权限对照（详见 [`API接口设计.md`](API接口设计.md)）：

| 角色 | 编码 | 权限范围 |
|------|------|----------|
| 管理员 | ADMIN | 全部功能 + 班级/用户管理 |
| 教师 | TEACHER | 题库/试卷/考试/阅卷/统计（不含班级用户的增删改） |
| 学生 | STUDENT | 查看考试、在线答题、查看成绩 |

### 5. 启动初始化 `DataInitializer`

应用启动时自动执行，创建默认管理员 `admin / 123456`（BCrypt 加密）与三个角色，保证首次部署即可登录。

## 五、关键设计要点

1. **题目-试卷解耦**：组卷通过 `paper_question` 快照分值，见 [`数据库设计.md`](数据库设计.md)。
2. **自动判分引擎**：在 `AnswerServiceImpl` 中，交卷时按题型判分——单选/判断精确匹配，多选按"完全正确得满分、漏选给部分分"，填空/简答支持「得分点 + 等价答案 + 权重」语法。
3. **Excel 导入导出**：基于 EasyExcel，`QuestionExcel` / `ScoreExcel` 定义列映射，批量导入题目、导出成绩。
4. **接口文档**：Knife4j 在线调试，启动后端后访问 `http://localhost:8080/doc.html`。

## 六、启动

```bash
cd exam-backend
mvn spring-boot:run
```

数据库连接参数通过环境变量 / `.env.properties` 注入，密码不写入仓库，详见根目录 [README](../README.md)。
